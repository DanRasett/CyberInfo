# Handoff: hover-контролы объектов карты

## Что сделано

- Кнопка удаления стены добавлена внутрь клетки рядом с `↺`.
- Для подписей добавлена кнопка удаления внутри клетки.
- Контролы скрыты по умолчанию: `opacity: 0`, `pointer-events: none`.
- При наведении на клетку контролы плавно проявляются за `180ms`.
- Прежний инструмент удаления `⌫` сохранён.

## Проверка

- Playwright подтвердил скрытое состояние контролов до наведения.
- Playwright подтвердил `opacity: 1` и `pointer-events: auto` после наведения.
- Playwright подтвердил, что кнопки остаются внутри клетки.
- Playwright подтвердил поворот стены и удаление стены.
- `npm run build` выполнен успешно.
- Impeccable detector вернул пустой список проблем.
