# Handoff: автоматический размер текста в клетке

## Что сделано

- Для каждой подписи рассчитывается размер шрифта по длине текста, переносам и доступным `88x88px` внутри клетки.
- Короткие подписи отображаются крупнее, длинные автоматически уменьшаются.
- Максимальное число строк рассчитывается по доступной высоте.
- В крайнем случае используется `ellipsizeMode="tail"` и минимальный масштаб `0.5`.

## Проверка

- Playwright подтвердил уменьшение короткого текста с `16px` до `11px` для длинной подписи.
- Playwright подтвердил, что длинный текст остается внутри границ клетки.
- `npm run build` выполнен успешно.
- `git diff --check` выполнен без ошибок.
- Impeccable detector вернул пустой список проблем.
- Во время браузерной проверки SmartShell API вернул `500` для `/api/smartshell/hosts` и `/api/smartshell/shift`; приложение использовало резервные данные.
