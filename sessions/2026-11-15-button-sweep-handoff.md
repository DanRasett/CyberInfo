# Handoff: hover-анимация кнопок

## Что сделано

- Для кнопки `РЕДАКТОР КАРТЫ` добавлен полупрозрачный слой, поднимающийся снизу при наведении.
- Такой же эффект добавлен для кнопки `Обновить`.
- Переход слоя выполняется за `300ms` с easing `ease-out`.
- Фоновые и текстовые цвета обеих кнопок сохранены.

## Проверка

- Playwright на `1920x1080` подтвердил движение слоя с `translateY(96px)` до `translateY(14px)`.
- Playwright подтвердил сохранение цветов: редактор `rgb(17, 24, 33)`, обновление `rgb(36, 139, 214)`.
- `npm run build` выполнен успешно.
- Impeccable detector вернул пустой список проблем.

## Следующий шаг

Визуально проверить эффект на kiosk-экране в браузере с реальным наведением мыши.
