# Handoff: масштабирование карты в редакторе

## Что сделано

- В toolbar редактора добавлены кнопки `−`, текущий процент и `+`.
- Доступны уровни `75%`, `100%`, `125%`, `150%` относительно автоматического масштаба карты.
- Кнопка с процентом сбрасывает масштаб к `100%`.
- Масштаб применяется только к редактору; kiosk-обзор продолжает использовать автоматический fit.
- Перетаскивание мест и размещение объектов используют фактический масштаб редактора.

## Проверка

- Playwright подтвердил изменение ширины карты с `1056.36px` до `1320.45px`.
- Playwright подтвердил ограничение максимального уровня `150%`.
- Playwright подтвердил сброс к `100%`.
- Playwright подтвердил размещение стены в правильной клетке после zoom.
- `npm run build` выполнен успешно.
- Impeccable detector вернул пустой список проблем.
