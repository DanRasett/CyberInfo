# Handoff: 2026-11-15 kiosk first pass

## Коротко

Сделан первый проход по дизайну kiosk на целевом viewport 1920x1080. Мобильная версия не учитывалась.

## Что изменилось

- `App.tsx`: добавлен статус SmartShell, счётчик свободных мест, время последней проверки и повторное обновление.
- `src/smartshell.ts`: добавлены метаданные `live/fallback` без изменения существующих функций API.
- `App.tsx`: масштаб редактора ограничен высотой целевого экрана, увеличены map-seat детали и touch targets toolbar.
- `App.tsx`: актуальный период тарифов выделяется по текущему дню, loading-текст исправлен для тёмной панели.
- `src/web.css`: убрана синяя полоса от html-фона.

## Проверка

- `npm run build` — успешно, 265 modules.
- `git diff --check` — без ошибок.
- `npm run web` — Vite route отвечает HTTP 200, title `Cyber Street`.
- `impeccable detect` — новых механических проблем нет; осталось предупреждение generic `Inter`.

## Что осталось

- Разделить публичный kiosk и защищённый операторский режим.
- Переработать геометрию карты: места всё ещё слишком мелкие и собраны в небольшой области.
- Сделать editor map actions доступными для touch/screen-reader и подтвердить destructive reset.

## Следующий шаг

Проверить и согласовать способ доступа оператора к редактору, затем убрать административные поля из публичного kiosk.
