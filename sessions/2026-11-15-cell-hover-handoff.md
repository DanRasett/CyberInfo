# Handoff: hover-подсветка клеток карты

## Что сделано

- У клеток редактора скруглены углы радиусом `8px`.
- При наведении контур клетки плавно меняет цвет на синий.
- Подсветка вычисляется по координатам курсора с учетом масштаба карты.
- За один момент подсвечивается только клетка под курсором.
- Размер клетки не меняется при наведении.

## Проверка

- Playwright на `1920x1080` подтвердил `border-radius: 8px`.
- Playwright подтвердил CSS-переход `border-color 180ms`.
- Playwright подтвердил синий цвет `rgb(36, 139, 214)` при наведении.
- Playwright подтвердил снятие подсветки с предыдущей клетки.
- `npm run build` выполнен успешно.
- Impeccable detector вернул пустой список проблем.
