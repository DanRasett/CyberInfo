# CyberInfo

CyberInfo — веб-интерфейс для smart-киоска компьютерного клуба. Сайт показывает доступность PC-хостов, карту клуба, локальные тарифы и акции. Встроенный редактор позволяет менять карту и сохранять её настройки в браузере.

## Стек

- React + TypeScript
- Vite
- CSS
- SmartShell GraphQL API через серверные маршруты `/api/smartshell/*`

## Запуск локально

```powershell
npm install
npm run web
```

Откройте `http://localhost:5173/`. Если порт занят, Vite выберет следующий свободный порт и покажет его в консоли.

## Проверка сборки

```powershell
npm run build
```

## SmartShell

Для получения реальных хостов создайте локальный `.env` на основе `.env.example` и укажите:

```text
SMARTSHELL_LOGIN=...
SMARTSHELL_PASSWORD=...
SMARTSHELL_COMPANY_ID=...
```

Файл `.env` не должен попадать в Git. Если переменные не заданы или SmartShell недоступен, интерфейс показывает состояние недоступной карты и не выдаёт fallback-хосты за реальные.

Статусы PC обновляются автоматически каждые 30 секунд. Тарифы не загружаются из SmartShell: они задаются локально в редакторе и сохраняются в `localStorage`.

## Редактор карты

В редакторе можно:

- добавлять и перемещать элементы по сетке;
- рисовать прямые стены;
- редактировать тарифы и акции;
- сохранять изменения кнопкой «Сохранить».

Карта, тарифы и акции хранятся в `localStorage` текущего браузера.

## Деплой в Vercel

Подключите GitHub-репозиторий как проект Vercel. Используются настройки из `vercel.json`:

- Build Command: `npm run build`
- Output Directory: `dist`

В окружение `Preview` или `Production` добавьте `SMARTSHELL_LOGIN`, `SMARTSHELL_PASSWORD` и `SMARTSHELL_COMPANY_ID`, затем выполните redeploy.

## Основные файлы

- `App.tsx` — экран клуба и редактор.
- `src/main.tsx` — точка входа браузерного приложения.
- `src/web.css` — стили веб-интерфейса.
- `src/smartshell.ts` — клиент загрузки хостов и нормализации статусов.
- `api/smartshell/` — серверные маршруты для Vercel.
- `vite.config.ts` — локальные API-маршруты Vite.
- `vercel.json` — настройки сборки Vercel.
